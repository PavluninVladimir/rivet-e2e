# Безопасность

Об уязвимостях Rivet сообщайте только приватно, через **GitHub Security
Advisories**
[основного репозитория](https://github.com/PavluninVladimir/rivet/security/advisories/new)
(вкладка **Security → Report a vulnerability**). Не открывайте issue и PR с
описанием дыры, пока она не исправлена.

*English: please report vulnerabilities privately through GitHub Security
Advisories of the main repository. Do not open public issues for security
problems.*

Модель угроз, поддерживаемые версии и что считается уязвимостью описаны в
[SECURITY.md основного репозитория](https://github.com/PavluninVladimir/rivet/blob/main/SECURITY.md).

Сценарий, который воспроизводит дыру, присылайте в том же приватном
отчёте, а не PR в этот репозиторий: публичный PR раскрыл бы её до
исправления.
