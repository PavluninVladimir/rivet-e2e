# Как участвовать

Сквозные сценарии Rivet живут по общим правилам проекта: язык, OpenSpec,
ветки, коммиты и CLA описаны в
[CONTRIBUTING.md основного репозитория](https://github.com/PavluninVladimir/rivet/blob/main/CONTRIBUTING.md).
Здесь только то, что относится к e2e.

*English speakers: issues and pull requests in English are welcome, but the
project language is Russian. Contributions require signing the
[CLA](https://github.com/PavluninVladimir/rivet/blob/main/CLA.md).*

## Правила сценариев

- **Сценарий ходит через интерфейс, как человек.** Прямые вызовы API
  допустимы для подготовки стенда и для сверки с тем, что показывает
  консоль, а не вместо действий пользователя.
- **Стенд только тестовый:** fake-хостинг, `fake-llm`, локальный
  bare-репозиторий. Настоящие репозитории, ключи моделей и токены в
  сценарии не попадают. Пароль и ключ стенда генерируются на каждый прогон.
- **Сценарий не зависит от соседей.** Свои имена с отметкой времени,
  никаких ожиданий порядка прогона.
- **Ожидания по видимому**: роль и подпись элемента, а не CSS-класс, там,
  где это возможно.

## Проверки перед PR

Раскладка репозиториев и запуск описаны в [README.md](README.md):

```sh
npx playwright test
```

Если правка идёт вместе с изменением rivet или rivet-web, ветки называются
одинаково: CI e2e берёт одноимённые ветки этих репозиториев.

## Безопасность

Об уязвимостях не пишите в issues и PR, только приватным отчётом, как
описано в [SECURITY.md](SECURITY.md).
